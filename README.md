# ilastik-mask-creation-tutorial
## Software Instructions
Download from here https://www.ilastik.org/download
download the stable version. 

Please follow the instructions in **`ilastic_Software_Guide.pdf`** to learn how to use the software and understand the complete workflow.

### Recommended Steps

1. Read **`ilastic_Software_Guide.pdf`** first to understand how to use the software.
2. Follow the step-by-step instructions provided in the guide.
3. After completing the software setup, use **`demo.py`** to run the file-sharing system.
4. Configure `demo.py` according to your system and follow the workflow described in the guide.
5. Some settings or code modifications may be required depending on your system configuration.

### Files

- **`ilastic_Software_Guide.pdf`** – Software user guide and step-by-step instructions.
- **`demo.py`** – Python code for running the file-sharing system.

**Please read the software guide before running `demo.py`.**
